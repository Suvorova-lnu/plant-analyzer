# Plant Analyzer — Аналіз стану рослин

Дипломний проєкт — мобільний веб-додаток для визначення хвороб рослин
за фотографією з використанням машинного навчання.

## Технології
- ML: Python, PyTorch, MobileNetV2, датасет PlantVillage
- Бекенд: FastAPI, PostgreSQL, JWT авторизація  
- Фронтенд: React, Vite, PWA
